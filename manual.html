このアプリは何をするもの？

Wemofについて公開されている考え方を、過去の5分足データで検証する研究ツールです。実際の注文は出しません。「±3σだから戻る」と決めつけず、値動きの純度や、ニュース・節目・高安値ブレイクなど“理由がありそうな動き”を分けて比較します。

Wemof本人の完全な売買ルールは公開数式ではありません。このアプリは公式再現ではなく、公開情報を検証可能な形にしたWemof-like仮説モデルです。

CSVの入れ方

OHLC CSVには次の列が必要です。列名は英語でも「始値・高値・安値・終値」でも認識します。

timestampopenhighlowclose
2026-08-27 09:00147.100147.130147.080147.120

イベントCSV（任意）は timestamp, title, importance を推奨します。イベント時刻の前後を「理由あり」として除外できます。

データがない場合は「サンプルで試す」を押してください。操作練習用の人工データが入ります。

判定ロジック

アプリは次の順で候補を絞ります。

  1. 異常検知：価格が設定したボリンジャーバンド±σまで届いたか。
  2. 純度：直近数本が同方向に揃い、実体が大きく、途中の押し戻しが少ないか。
  3. 理由あり除外：イベント時刻、直近高安値ブレイク、設定したラウンドナンバー付近ではないか。
  4. Wemof Score：異常度35%＋純度35%＋理由なし度30%で0〜100点化。
  5. 将来評価：候補の次の足からTP/SLのどちらへ先に到達したか、MAE/MFEを測ります。

同じ5分足の中でTPとSLの両方に触れた場合は、どちらが先か分からないため「同一足両到達」と表示し、期待値計算では保守的に損失扱いにしています。

「説明がつかない値動き」を完全自動で知るにはリアルタイムニュース全体が必要です。このMVPでは、イベントCSV＋価格構造で近似します。

結果の読み方

TP先行率：候補後に設定利確へ先に到達した割合です。これだけで安全性は判断しません。

MAE（Maximum Adverse Excursion）：利確・終了までの最大逆行幅。小さいほど途中の含み損が小さかったことを示します。

MFE（Maximum Favorable Excursion）：最大順行幅。「3pipsではなく5pips取れたか」などの研究に使えます。

期待値：設定TP/SL、時間切れ時の終値、往復コストを使った1候補あたり平均pipsです。

FILTER TEST：Wemofのフィルターを足すことで件数・勝率・MAE・期待値が改善するかを見る場所です。改善しないなら、そのフィルターに統計的価値があるとは言えません。

データについて

読み込んだ相場データは、このスマホ・PCのブラウザ内だけで計算します。サーバーには送信しません。

CSV本体と解析結果は再読み込みすると消えます。検証条件だけはこのブラウザ内に保存されます（詳しくは localStorage）。結果を残したい場合は「結果CSVを書き出す」を使います。

ブラウザのサイトデータを削除すると保存した設定も消えます。

間違えたとき・困ったとき

CSVが読めない列名に timestamp/date, open, high, low, close があるか確認。最低30本必要です。
候補が0件σ倍率や純度しきい値が厳しすぎる可能性があります。まずサンプルで動作確認してください。
候補が多すぎるσ倍率、純度しきい値、総合スコアを上げます。
結果が「同一足両到達」5分足だけでは足の中の順番が不明です。1分足など細かいデータで再検証すると精度が上がります。
設定を戻したい各欄を変更して再解析します。「深い損切り 3 / 100」「リスク制限 3 / 20」も使えます。
画面を閉じたCSVは再読込が必要です。結果CSVを書き出しておけば後から比較できます。

スマホで使う方法

iPhoneのSafariで公開URLを開き、共有ボタン →「ホーム画面に追加」でアプリのように起動できます。初回読み込み後は主要ファイルとこのマニュアルをオフラインでも開けるようにします。

大きなCSVはPCの方が扱いやすいです。スマホではサンプル確認や結果閲覧をおすすめします。

用語集

Wemof-likeWemofの公開説明をもとに、このアプリで数値化した近似モデル。公式ルールそのものではありません。
ボリンジャーバンド移動平均の周囲に標準偏差を使って幅を作る指標。
σ（シグマ）標準偏差の倍率。ここでは「普段からどれだけ離れたか」を見る目安。
純度一方向に揃って進み、押し戻しが少ない値動きを0〜100で近似した独自スコア。
MAEその候補を持ったと仮定したときの最大逆行幅。
MFE最大順行幅。
pipsFXの値幅単位。USD/JPYではこのアプリは1 pip = 0.01円として計算。
ラウンドナンバー147.00、147.50のように人が意識しやすい切りのよい価格。
